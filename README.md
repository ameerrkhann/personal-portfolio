# 🌐 Personal Portfolio

## 🚀 Overview
This is my **personal portfolio website**, designed to showcase my skills, experience, and projects. Built with a modern and responsive design, this portfolio serves as a professional space where visitors can explore my background in **AI, cybersecurity, and software development**.

## 🛠️ Technologies Used
- **HTML, CSS, JavaScript**
- **React.js** 
- **Framer Motion** (for animations)
- **Netlify** (for deployment)

## 🎨 Features
✅ **Modern & Minimalist UI** – Clean and professional design  
✅ **Fully Responsive** – Optimized for desktop, tablet, and mobile devices  
✅ **Project Showcase** – Highlights key projects with live links and descriptions  
✅ **Smooth Animations** – Enhances user experience with transitions and effects  
✅ **Contact Section** – Allows visitors to easily connect
